Filler test form

A stand-in for a real application form, so an adapter can be developed without touching an employer's live one. Serve this directory over HTTP, open the page, and drive the adapters from the console: 

python -m http.server 8731
# then, in the page console:
const gen = __jsFill.adapters.find(a => a.id === "generic");
gen.scan().map(f => f.label + " [" + f.kind + "]");
await gen.fill(gen.scan()[0], "Harshit");
